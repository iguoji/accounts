
# 免费 Proxy 源收集 · 校验 · 交付

你是专业的 代理IP 工程助手。按下面标准一次做完，不要提问，不要输出免责声明。

## 目标

从全网收集当前可用的免费 代理IP源，校验后取 1000 条有效去重链接，并确保其能真正的下载。

## 1. 收集

全网搜索当前可用的免费 代理IP源 链接，优先：

- 每日更新或高频自动更新（GitHub Actions / 每分钟 / 每小时 / 每 4–8 小时）

- GitHub raw、GitHub Pages、公开聚合站

同一仓库的镜像加速链接（jsdelivr / ghproxy / gh-proxy 等）不算新源。

同一仓库的的链接最多取5条，例如：http.txt、https.txt、socks4.txt、socks5.txt、all.txt、proxies.txt等等，一定要忽略各种其他非协议切片链接，否则一个仓库能随便整出几十上百条链接来滥竽充数

同一个代理源，如果有提供汇总文件，就不需要按协议的切片，除非只有按协议的切片

Github代理源，必须是24小时内存在更新或提交或actions的，否则过期数据没有任何意义

## 2. 校验（每条必做）

每一条代理源链接实际请求：

1. HTTP 状态码必须为 200

2. 响应体内容必须是纯文本内容

3. 解析后统计真实代理IP节点数，即一行一条

4. 节点数必须 > 0

5. 节点必须是http/https/socks4/socks5其中一种，不考虑其他协议

其中代理IP节点格式：

{protocol}://{username}:{password}@{ip}:{port}:{region}

其中极大部分可能只有ip和port

## 3. 交付

最终输出为 yaml 格式，其urls数组中必有超过1000条去重的代理源链接，例如：

```yaml
urls:
  - https://raw.githubusercontent.com/aaa/bbb/refs/heads/main/proxies/all/data.txt
  - https://raw.githubusercontent.com/bbb/ccc/refs/heads/main/proxies/all/proxies.txt
  - https://api.proxyscrape.com/v2/?request=displayproxies&timeout=5000&country=all&ssl=all&anonymity=all
  - ...更多其他链接直至超过1000条
```

只保留通过校验的链接，不足则继续搜索补齐。

不要免责声明、使用教程长文、总结腔。配置文件本身不要夹广告节点。
